# Financial Ratio Benchmarks by Sector

These are approximate medians — compare a stock against its own sector, not the whole market.

## Technology (Software/SaaS)
| Metric | Typical Range |
|--------|--------------|
| Gross Margin | 65–85% |
| Operating Margin | 15–35% (mature) / negative (growth) |
| P/E (Forward) | 25–50x |
| EV/Revenue | 5–15x |
| FCF Margin | 20–35% |
| Revenue Growth | 15–30% (high growth) |

## Technology (Hardware/Semiconductors)
| Metric | Typical Range |
|--------|--------------|
| Gross Margin | 40–65% |
| Operating Margin | 20–35% |
| P/E (Forward) | 20–35x |
| EV/EBITDA | 15–25x |

## Consumer Discretionary
| Metric | Typical Range |
|--------|--------------|
| Gross Margin | 30–50% |
| Operating Margin | 8–18% |
| P/E | 18–30x |
| EV/EBITDA | 12–20x |

## Healthcare / Pharma
| Metric | Typical Range |
|--------|--------------|
| Gross Margin | 60–85% (specialty pharma) |
| R&D as % Revenue | 15–25% |
| P/E | 20–40x |
| EV/EBITDA | 15–25x |

## Financials (Banks)
| Metric | Typical Range |
|--------|--------------|
| P/B | 1.0–2.5x |
| P/E | 10–18x |
| ROE | 10–18% |
| Net Interest Margin | 2.5–4.5% |

## Industrials
| Metric | Typical Range |
|--------|--------------|
| Gross Margin | 25–45% |
| Operating Margin | 10–20% |
| P/E | 15–25x |
| EV/EBITDA | 10–18x |
| ROIC | 12–25% |

## Energy
| Metric | Typical Range |
|--------|--------------|
| EV/EBITDA | 4–10x (highly cyclical) |
| FCF Yield | 6–12% at cycle peaks |
| Debt/EBITDA | <2x preferred |

---

## Universal Thresholds (Across Sectors)

| Metric | Strong | Acceptable | Weak |
|--------|--------|-----------|------|
| ROE | >20% | 12–20% | <12% |
| ROIC | >15% | 8–15% | <8% |
| Current Ratio | >2.0 | 1.5–2.0 | <1.5 |
| Interest Coverage | >10x | 5–10x | <5x |
| Debt/Equity | <0.5 | 0.5–1.5 | >1.5 |
| FCF Margin | >20% | 10–20% | <10% |
